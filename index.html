Information has a freshness state

Weather and alerts change quickly. Route facts change slowly. Camping, access and closures each have their own cadence. High Colorado shows when a value was updated instead of making stale data look live.

⚠ NWS alerts~5 min while active
🌦 Climb-day forecast~15 min
🚙 Access / closuresHourly near departure
🏕 Camping / permitsPeriodic + pre-trip recheck
